# Security and responsible handling

- Never commit passwords, private keys, service-role keys, API tokens, session cookies or real candidate documents.
- The Supabase configuration in this export is a placeholder. Use only browser-safe publishable credentials in client code.
- Configure SMTP and TURN credentials in the appropriate provider/server environment, not the repository.
- Review tenant isolation, role permissions and file access when changing API routes.
- Keep evidence-based matching advisory. A missing excerpt is not proof that a person lacks a skill.
- Do not submit real résumés, private contact details or exploit secrets in public issues. Contact the repository owner privately to arrange a secure report.

Automated regression tests are not a security audit. Production authentication and video-call behavior require deployment-specific validation.
